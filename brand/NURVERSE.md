# NURVERSE — standar channel (dibaca semua karyawan AI)

Nama: NURVERSE (nur = cahaya). Bahasa: Indonesia. Nada: tenang, hangat, menguatkan; bukan menggurui, bukan menakut-nakuti.

## Tampilan (tetap, jangan berubah-ubah)
- Latar biru malam `#071a2b`→`#0c2c44`; aksen emas `#e3b341`; zamrud `#18a58a`; teks gading `#f6efdc`.
- Motif geometris Islami (bintang 8 sudut, arabesk, cahaya, bulan sabit, kubah, gelombang). Gerak lambat dan halus.
- Arab: font Amiri. Latin: Inter. Satu adegan = satu gagasan; maksimal 3 baris teks.
- Tanda air kecil "NURVERSE" di pojok. Tanpa musik berlirik; hanya ambient lembut.

## Aturan konten (WAJIB, dicek mesin)
1. Tidak ada gambar makhluk bernyawa: tanpa wajah, tanpa sosok manusia, tanpa menggambarkan Nabi, malaikat, sahabat.
2. Ayat Al-Qur'an hanya dari API terverifikasi (Arab + terjemah + rujukan). Teks ayat tidak ditulis model dan tidak dibaca suara sintetis (Al-Qur'an tidak "dilantunkan" TTS); yang dibaca hanya terjemahannya.
3. Hadis hanya dari API terverifikasi. Tidak ada hadis terverifikasi = tidak boleh menyebut "hadis" atau "bersabda".
4. Tidak berfatwa, tidak memvonis halal/haram, tidak menyentuh politik praktis, takfir, perselisihan mazhab, tafsir mimpi, klaim penyembuhan, ramalan.
5. Tidak mengutip perkataan ulama kecuali sumbernya terverifikasi; lebih baik parafrase tanpa atribusi palsu.
6. Tidak ada angka/fakta tanpa sumber. Tidak ada klaim sains yang dipaksakan ke ayat.
7. Ada jeda dan penutup menenangkan; ajakan hanya satu per video (bagikan / komentar / berlangganan).

## Gaya naskah
- Hook 3 detik pertama: menyapa "kamu", spesifik, ada taruhan atau teka-teki; tanpa "Assalamualaikum, halo sobat, selamat datang…".
- Kalimat pendek, bahasa lisan sehari-hari, satu napas satu kalimat.
- Tiap video punya satu janji di judul dan satu jawaban di penutup.

## Judul & thumbnail
- Judul ≤ 60 huruf, inti di 40 huruf pertama, maksimal 2 kata KAPITAL.
- Teks thumbnail ≤ 3 kata dan tidak mengulang judul.
